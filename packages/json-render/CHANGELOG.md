# @drupal-canvas/json-render

## 0.2.0

### Minor Changes

- c4e025b: Add standalone json-render packages for Canvas component trees, with
  shared contracts and renderers for React, Astro, Vue, and Angular.

  The framework renderers support the Canvas-specific markup required by the
  Canvas editor, including component, slot, and region markers and empty drop
  targets in preview mode.
