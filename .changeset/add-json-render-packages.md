Add standalone json-render packages for Canvas component trees, with shared
contracts and renderers for React, Astro, Vue, and Angular.

The framework renderers support the Canvas-specific markup required by the Canvas
editor, including component, slot, and region markers and empty drop targets in
preview mode.
