Add Angular 21 and 22 bindings for headless Canvas rendering, server-side draft sessions, and component discovery.

- Render component trees with scoped slots and hydration-safe component identity.
- Integrate draft previews, content navigation, and server endpoints with Angular SSR.
- Generate component registries and metadata with the `canvas-angular` build and watch command.
