title: Contributed modules
description: Drupal.org projects that extend Canvas and have at least one release.

These contributed projects extend Canvas and have at least one release on
Drupal.org. They are maintained by their own authors, not by the Canvas
maintainers. Check each project page for its stability, supported Canvas
versions, and security coverage before you install it.

To add a project, open a merge request that edits this page. The project needs
at least one release on Drupal.org.

For the more adventurous, the [Canvas ecosystem](https://www.drupal.org/project/canvas/ecosystem)
on Drupal.org lists every project that declares Canvas support, including ones
that are not reviewed for this page or have no release yet.

## Components and design systems

- [Canvas Bootstrap](https://www.drupal.org/project/canvas_bootstrap): Bootstrap 5 components, such as buttons, containers, rows, and columns.
- [Canvas Grid Section](https://www.drupal.org/project/cgs): Nestable grid and grid item components that set the layout, so other components only handle their own style.
- [Canvas Jumbotron](https://www.drupal.org/project/canvas_jumbotron): A jumbotron code component.
- [Canvas Map](https://www.drupal.org/project/canvas_map): Google Maps and OpenStreetMap components.
- [Canvas MUI Button](https://www.drupal.org/project/canvas_mui_button): A Material Design 3 button code component.
- [Canvas MUI Card](https://www.drupal.org/project/canvas_mui_card): A Material Design 3 card code component.
- [Canvas Palette](https://www.drupal.org/project/canvas_palette): A kit of single-directory components inspired by Extra Paragraph Types.
- [Canvas Studio Tailwind](https://www.drupal.org/project/canvas_studio_tailwind): Tailwind CSS mappings and components for Canvas Studio.
- [DROWL Canvas](https://www.drupal.org/project/drowl_canvas): Style groups for Canvas Builder, plus button, heading, text, and image components.
- [Layout Components](https://www.drupal.org/project/layout_components): Columns, rows, grids, containers, tabs, and other layout components.

## Component sources and props

- [Canvas Entity Reference](https://www.drupal.org/project/canvas_entity_reference): Entity reference props for taxonomy terms, nodes, users, media, and custom blocks.
- [Canvas Field Component](https://www.drupal.org/project/canvas_field_component): Places rendered field output, with a chosen formatter, in content templates.
- [Canvas Focal Point Widget](https://www.drupal.org/project/canvas_focal_point_widget): A focal point and scale picker for image props, set per component instance.
- [Canvas Icon Picker](https://www.drupal.org/project/canvas_icon_picker): A visual icon picker for string props, backed by the core Icon API.
- [Canvas Pattern Blocks](https://www.drupal.org/project/canvas_pattern_blocks): Exposes patterns as blocks, so a placed pattern stays centrally managed.
- [Canvas Pattern Components](https://www.drupal.org/project/canvas_pattern_components): Exposes patterns as components, so pattern edits update every placement.
- [Canvas Remote Video](https://www.drupal.org/project/canvas_remote_video): A remote video prop shape backed by oEmbed media types, such as YouTube and Vimeo.
- [Curated Colors](https://www.drupal.org/project/curated_colors): A color swatch picker for string props, backed by named, exportable palettes.

## Editor experience

- [Canvas Accessibility](https://www.drupal.org/project/canvas_a11y): Checks pages for accessibility issues while you edit and shows which component causes each one.
- [Canvas Builder](https://www.drupal.org/project/canvas_builder): Background, spacing, and typography style controls for component instances.
- [Canvas Component Access](https://www.drupal.org/project/canvas_component_access): Restricts which components each user role can use.
- [Canvas Content Editor](https://www.drupal.org/project/canvas_content_editor): Edits a Canvas component tree as a stream of blocks in the regular content edit form.
- [Canvas Full HTML](https://www.drupal.org/project/canvas_full_html): Enables the Full HTML text format in rich text editors.
- [Canvas Interactive Toggle](https://www.drupal.org/project/canvas_interactive_toggle): A toggle to click-test interactive components, such as tabs and accordions, in the editor.
- [Canvas Link Autocomplete](https://www.drupal.org/project/canvas_link_autocomplete): Adds Canvas pages to link field autocomplete suggestions.
- [Canvas Page Compare](https://www.drupal.org/project/canvas_page_compare): A Compare tab that lists the components added, removed, edited, and moved between two versions of a page.
- [Canvas Page Weight](https://www.drupal.org/project/canvas_page_weight): An editor panel that shows how heavy a page is and what to change to make it lighter.
- [Canvas Studio](https://www.drupal.org/project/canvas_studio): A design system editor with configurable prop-to-CSS-class mappings and framework presets.
- [Canvas Styles](https://www.drupal.org/project/canvas_styles): A form-based UI for editing design tokens, such as colors, typography, and spacing.
- [Drupal Canvas Groups](https://www.drupal.org/project/canvas_groups): Organizes component props into configurable groups in the component form.

## Pages and content templates

- [Canvas Accelerator Page Fields](https://www.drupal.org/project/canvas_fields): Enables Field UI for the Canvas page entity.
- [Canvas Block Twig Suggestions](https://www.drupal.org/project/canvas_block_twig_suggestions): Region-aware Twig template suggestions for blocks placed in Canvas.
- [Canvas Entities](https://www.drupal.org/project/canvas_entities): Content templates for paragraph and taxonomy term entities.
- [Canvas Menu Manager](https://www.drupal.org/project/canvas_menu_manager): A drag-and-drop menu editor in the page data panel.
- [Canvas Override](https://www.drupal.org/project/canvas_override): Per-content layout overrides of a content template, for selected content types.
- [Canvas Page Menu](https://www.drupal.org/project/canvas_page_menu): Menu link selection and Pathauto alias suggestions for Canvas pages.
- [Canvas Page Metatag](https://www.drupal.org/project/canvas_page_metatag): The full set of Metatag groups on Canvas pages.
- [Canvas Paragraphs](https://www.drupal.org/project/canvas_paragraphs): Content templates for paragraph entities.
- [Group Canvas](https://www.drupal.org/project/group_canvas): Manages Canvas pages as Group content.

## Multilingual

- [Canvas Translate](https://www.drupal.org/project/canvas_translate): A side-by-side translation workspace delivered as a Canvas extension.

## Developer tools

- [Canvas Tailwind](https://www.drupal.org/project/canvas_tailwind): Shares one Tailwind build, set of design tokens, and stylesheet between a Tailwind theme and code components.
- [Code component](https://www.drupal.org/project/code_component): Exposes code components as single-directory components, so Twig templates can include them.

## AI and automation

- [AI Agents Canvas Direct Edit](https://www.drupal.org/project/ai_agents_canvas_direct_edit): Resolves simple prop edits requested through Canvas AI without a model call.
- [Canvas AI SEO](https://www.drupal.org/project/canvas_ai_seo): AI-generated Schema.org JSON-LD for Canvas pages.
- [Canvas Prompt Generator](https://www.drupal.org/project/canvas_prompt_generator): Generates Canvas AI prompts from a description or a screenshot.
- [Canvas Tools](https://www.drupal.org/project/canvas_tools): Tool API operations for building pages and templates from AI agents, Drush, or code.
